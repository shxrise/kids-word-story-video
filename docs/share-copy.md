# 项目分享文案

以下文案用于项目正式发布后的社区分享。发布前请根据具体平台缩短或调整格式。

## 中文短版

我开源了一个面向中文家庭的 Codex 儿童英语单词故事视频技能：输入一组英语单词，它会先确认需求，再创作连贯故事、生成绘本插画和中英混合旁白，最终输出完整 MP4。仓库内有 60 秒成品演示、安装方法和完整 QA 流程。

https://github.com/shxrise/kids-word-story-video

如果对你有帮助，欢迎试用、反馈或点一个 Star。

## 中文长版

这是我的第一个公开 Vibe Coding 项目。它不是逐词拼画面的简单脚本，而是把英语目标词自然编进一段约 5～6 分钟的儿童故事，并完成角色设定、绘本插画、真实 TTS、目标词视觉提示、Remotion 渲染和交付前 QA。

项目主要面向中文用户，仓库提供中英文说明、60 秒视频演示和一条可以直接交给 Codex 的安装提示。欢迎家长、教师和 Vibe Coding 爱好者试用并告诉我哪里还可以改进。

https://github.com/shxrise/kids-word-story-video

## English

I open-sourced a Codex skill that turns a list of English target words into a coherent children’s picture-book story video with Chinese-led, mixed Chinese-English narration. It includes confirmation before production, real TTS duration checks, consistent illustrations, synchronized word labels, Remotion rendering, and a verifiable QA workflow.

The repository includes a 60-second demo and copy-paste installation instructions:

https://github.com/shxrise/kids-word-story-video

Feedback and Stars are welcome if you find it useful.
