# 开工确认单

每个新视频请求都先显示下列确认单，并明确写“尚未开工”。目标词数量和列表按用户实际输入填写；场景数、时长和故事偏好是建议值，不机械计算。确认前不得执行任何制作动作。

```text
【儿童单词故事视频制作确认单——尚未开工】

目标词：<数量>个
单词：<完整列表>
故事来源：根据目标词自动原创
故事偏好：模型自由发挥，轻松、有趣、适合儿童
主角偏好：由本次故事自动选择
适合年龄：4～7岁
预计场景：约21幕，允许按剧情在18～25幕内调整
预计时长：约4～5分钟，最终由旁白和可选停顿自然决定
制作流程：确认后一次性完成
插画画风：全彩儿童绘本水彩
插画规格：生成器源图自动稳定规格化为16:9、1280×720
成片规格：1280×720、20fps（固定规格）
画面处理：比例偏差不超过1.0%时自动Lanczos规格化，不裁切、不补边，无需再次确认
旁白：温和女声
语速：偏慢
音效密度：标准，每幕0～2个，自动避让旁白
固定规则：中文主体旁白；目标词至少自然出现2次；读词后默认停顿0秒（可改为0.3秒、1秒等）；放大两级的半透明白底英文词标随读词显示；画内底部小字幕
标题：自动生成全中文标题并朗读

请回复“按默认设置开始”，或直接说出要修改的项目。
```

可修改且实现稳定的项目：故事基调、主角类型、年龄、场景范围、时长倾向、一次完成或先审故事、女声/男声/儿童感声音、语速、音效密度、三种画风预设、标题自动或指定。分辨率和帧率固定，不提供其他选项。不要主动展示编码器、FFmpeg、坐标、分贝等底层参数。

回复示例（约100字）：

> 按默认设置开始；改成女声、18幕、轻松搞笑后开始；采用温暖冒险、动物主角、少量音效，先看故事；标题用《月亮邮差》，语速慢一点、画风改成明亮蜡笔；控制在5分钟内，音效丰富些；先试听男声、女声和儿童感声音再决定。

用户回复只修改所点名的项目，其余沿用确认单默认值。若用户选择试听声音，只生成几秒试听样本，不开始故事或视频制作。
